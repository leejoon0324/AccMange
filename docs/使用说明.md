# 双钥使用说明

## 开始使用

1. Android 手机打开 APK 并安装；iPhone 使用 iOS 工程在 Xcode 中签名安装。
2. 首次打开，设置并确认至少 8 个字符的主密码，建议使用较长的密码短语。
3. 牢记主密码，应用没有密码找回服务。

## 添加动态验证码

1. 在需要保护的服务中开启双重验证，选择“认证器应用”。
2. 双钥中点击“添加账号”→“扫描二维码”，允许相机权限。
3. 扫描服务提供的认证器二维码，核对名称与账号，点击“加密保存”。
4. 将生成的验证码填回该服务，完成启用。妥善保存服务提供的恢复码。

没有二维码时，选择“手动添加验证账号”，填写服务名称、账号和服务提供的 Base32 密钥，也可粘贴标准 otpauth 链接。高级设置必须与服务要求一致。

动态验证码无需联网。若提示验证码错误，请开启系统自动设置时间，等待下一轮验证码后重试。HOTP 不会按时间刷新，仅在当前验证码已使用后点击“下一个验证码”。

## 管理账号和密码

- 在“动态验证码”与“密码保险箱”之间切换。
- 使用搜索框、分组和收藏筛选账号。
- 卡片菜单支持编辑与删除。
- 点击验证码或复制按钮即可复制，30 秒后会尝试清除剪贴板。
- “保存账号密码”可保存密码、网站和备注，也可生成 20 位强密码；密码默认隐藏。
- 右上角锁图标立即锁定；在“安全与备份”中开启指纹 / Face ID（设备须已配置生物识别）。

## 备份和迁移

1. 打开“安全与备份”→“导出加密备份”。
2. 设置独立备份密码，在系统分享菜单将 `.twinlock` 文件保存到安全位置。
3. 新设备先创建保险箱，再选择“导入加密备份”，选文件并输入导出时的备份密码。
4. 记录合并导入，同一记录编号保留较新版本，不会删除其他记录。

主密码解锁当前设备，备份密码解密备份文件，两者可以不同。更换手机或卸载应用前务必备份，并检查备份可以导入。

## 支持范围

Android 7.0+、iOS 15.5+。支持标准 TOTP/HOTP 二维码，不支持 Google 批量迁移码。浏览器仅为临时体验版，刷新清除数据。目前没有密码自动填充或云同步。
