# 双钥 1.1.0 使用说明

## 开始使用

1. Android 手机打开 APK 安装；此版本 IPA 未签名，日后签名后才能安装到 iPhone。
2. 首次打开即进入主界面，自动建立本机加密存储，无需设置主密码。
3. 返回应用直接使用，不会弹出主密码或指纹验证。

## 添加动态验证码

1. 在需要保护的服务中开启双重验证，选择“认证器应用”。
2. 双钥中点击“添加账号”→“扫描二维码”，允许相机权限。
3. 扫描服务提供的认证器二维码，核对名称与账号，点击“加密保存”。
4. 将生成的验证码填回该服务，完成启用。妥善保存服务提供的恢复码。

没有二维码时，选择“手动添加验证账号”，填写名称、账号和 Base32 密钥，也可粘贴标准 otpauth 链接。高级设置必须与服务要求一致。

动态验证码无需联网。若提示错误，请开启系统自动设置时间，等待下一轮后重试。HOTP 不会按时间刷新，当前验证码使用后再点“下一个验证码”。

## 管理账号和密码

- 在“动态验证码”与“密码保险箱”之间切换，使用搜索框、分组和收藏筛选。
- 卡片菜单支持编辑与删除，点击验证码或复制按钮即可复制。
- “保存账号密码”可保存密码、网站和备注，也可生成 20 位强密码。
- 本机文件使用设备随机密钥加密，应用直接打开；请使用手机本身的锁屏保护访问。

## 备份和迁移

1. 打开右上角“安全与备份”→“导出加密备份”。
2. 设置独立备份密码，在系统分享菜单保存 `.twinlock` 文件。
3. 新设备打开主界面后选择“导入加密备份”，选文件并输入该备份密码。
4. 同一记录编号保留较新版本，其他记录会保留。

备份密码只用于导出或导入备份，不用于启动应用。更换手机或卸载应用前务必备份，并检查备份可以导入。

## 从 1.0.0 升级

覆盖安装后直接进入主界面。若检测到旧版记录，会显示“发现旧版数据，点此导入”。点击后输入旧版主密码，记录会合并到当前加密存储；此后使用无需主密码。也可从“安全与备份 → 导入旧版数据”进入。旧版文件会保留，导入失败也不会覆盖。若忘记原密码，需要使用已导出的备份及其备份密码恢复。

## 支持范围

Android 7.0+、iOS 15.5+。支持标准 TOTP/HOTP，不支持 Google 批量迁移码。浏览器仅为临时预览，刷新清除数据。目前没有系统自动填充或云同步。
